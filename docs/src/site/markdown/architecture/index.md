# Architectural Decisions and Discussions

In order to drive better communication around architectural discussions and decisions we are creating
this repository for active and adopted proposals. Active proposals are proposals under discussion. 
Anyone may make or comment on an active proposal. Adopeted proposals are proposals that have been 
accepted are either under or awaiting the start of active development.

## How to submit a proposal

Submitting a proposal is as simple as cloning the git repository, creating a new markdown file in
this directory, editing this document to include a link to the new file, and submitting a pull request
for those changes.

The active proposal should include a brief synopsis of the change, why the change is desired, and 
some indication of how it might be implemented.  Once accepted a discussion will be created on GitHub
to accomidate the comments and changes.  As changes are accepted the proposal document should be updated.
